BMS Device Registration SOAP

POST http://183.83.216.66:9090/ezybms_m8/app/index.php/validateAuthentication
⚠ This is a SOAP XML endpoint (not REST)
• This is the first call the app makes — registers the device with the BMS (Business Management System)
• smsCode = MSO Key (first 4 chars) + Username concatenated
• Example: MSO Key h1i2 + Username itptest → smsCode = h1i2itptest
• appTypeId = 2 for mobile/Flutter app
• On success (statusCode=0), the response contains ipAddress — this is the actual REST API base URL (ends with /index.php/wsController)
• This returned URL is used as the base for validateLogin and all other REST endpoints
• Empty smsCode + device IMEI = auto-login check (is this device already registered?)
Server-side flow (validateAuthentication.php)
1. First-time registration (smsCode + imei):
  → Server extracts MSO Key = substr(smsCode, 0, 4), Username = substr(smsCode, 4)
  → Looks up dealer info via MSO Key → gets parent_url (REST server)
  → Validates employee on parent server → creates app registration → returns REST API URL in ipAddress
2. Subsequent logins (empty smsCode + imei):
  → Looks up employee by IMEI + appTypeId → returns stored REST API URL
3. Response fields: statusCode, statusMessage, ipAddress, employeeId, appThemeColor, appDashboard, appLogoPath, registrationRequired, version
